## 5. FAQ
**What is a WAF?**
A Web Application Firewall (WAF) filters and monitors traffic between a web application and the internet, blocking attacks like SQL injection, XSS and DDoS.

**Why does my website need a WAF?**
Web applications are a primary attack target. A WAF blocks automated and targeted attacks that application code alone can't stop.
